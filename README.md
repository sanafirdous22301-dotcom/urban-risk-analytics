# urban-risk-analytics
Integrated Urban Risk Analytics and Resource Prioritization System
Our development roadmap
1. Project foundation
   
   GitHub structure, documentation and dataset register.
   Folders pushed
2. Dataset selection
   
   Verify flood, heat and infrastructure datasets, their licences, labels, formats and spatial coverage.
3. Data preprocessing
   
   Clean and align data using common geographic zones.
4. ML development
   
   Build, compare and evaluate the individual risk models.
5. Integrated risk engine
   
   Combine the three risk dimensions and rank priority areas.
6. Backend and frontend
   
   Connect FastAPI, HTML, CSS, JavaScript, maps and charts.
7. Final validation
   
   Test the system, document limitations and prepare the demonstration.
